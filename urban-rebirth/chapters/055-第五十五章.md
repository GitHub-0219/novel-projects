# 第五十五章 苏瑶的秘密

陈默与苏瑶的联系越来越频繁。

每次见面，苏瑶都会带来一些关于血魔宗的情报。这些情报对陈默的计划至关重要。

但陈默发现，苏瑶似乎对他有着某种特殊的态度。

"陈默，你知道吗？"苏瑶在一次见面时突然说，"天机阁一直在关注你。"

"我知道。"陈默点了点头。

"不，你不知道。"苏瑶摇了摇头，"天机阁关注你，不仅仅是因为你的修为。而是因为……你的身份。"

陈默的眉头微皱："我的身份？"

苏瑶深深地看了陈默一眼，然后压低声音说："你是玄天道尊的转世。在修真界，这是一个极为特殊的身份。"

"玄天道尊，前世是修真界的天仙境强者。他曾经发现了地球灵气枯竭的真相，但还没来得及揭露，就陨落在了渡劫之中。"

"天机阁相信，你的重生，绝非偶然。你一定肩负着某种使命。"

陈默沉默了片刻。

他知道苏瑶说得对。他的重生，确实不是偶然。但他还不知道，自己到底肩负着什么使命。

"苏瑶，"陈默认真地说，"天机阁到底知道多少？"

苏瑶犹豫了一下，然后说："天机阁知道，地球灵气枯竭的背后，与仙界有关。但我们一直没有找到证据。"

"如果你能找到证据，天机阁愿意全力支持你。"

陈默点了点头。

他知道，天机阁是一个庞大的组织，掌握着大量的资源和情报。如果能获得天机阁的支持，对他调查灵气枯竭的真相，会有很大的帮助。

"好。"陈默说，"我会尽快找到证据的。"

苏瑶满意地点了点头。

"对了，"她突然说，"陈默，你要小心一个人。"

"谁？"

"天机阁的副阁主，张天师。"苏瑶的表情变得严肃，"他一直反对与你合作。他认为，你的存在，会打破修真界的平衡。"

陈默的眉头微皱。

"他会对我下手吗？"

"不确定。"苏瑶摇了摇头，"但你要小心。张天师是一个极为危险的人物，他的修为深不可测。"

陈默点了点头，心中涌起一股警惕。

天机阁内部，似乎也存在着矛盾和斗争。他需要小心行事，避免卷入天机阁的内部纷争。

"苏瑶，谢谢你。"陈默认真地说。

苏瑶微微一笑："不用谢。我只是……不想看到你出事。"

陈默看着苏瑶的表情，心中泛起一丝异样的感觉。

他知道，苏瑶对他的态度，已经超出了普通的情报合作关系。

但他没有多想，因为他心中只有林清雅。

"苏瑶，"陈默认真地说，"我有喜欢的人了。"

苏瑶的表情微微一僵，但很快恢复了正常。

"我知道。"她淡淡地说，"是林清雅吧？"

陈默点了点头。

苏瑶沉默了片刻，然后微微一笑。

"好吧。"她说，"那我们就做朋友吧。"

陈默松了一口气。

"好。"他说，"我们是朋友。"

苏瑶站起身，转身离开了。

陈默看着苏瑶离去的背影，心中泛起一丝复杂的情绪。

他知道，苏瑶是一个好女孩。但他心中只有林清雅，无法给她任何承诺。

"对不起，苏瑶。"陈默低声自语。

他收回思绪，继续思考接下来的计划。

血魔宗的威胁还没有解除，天机阁内部又出现了新的变数。他需要更加小心谨慎，才能在这场复杂的博弈中，取得最终的胜利。

"张天师……"陈默低声念着这个名字。

他有一种预感，这个人，将会成为他未来的一个重要对手。

但那是以后的事情了。

现在，他需要集中精力，消灭血魔宗的残余势力。

"血影，"陈默低声自语，"这一次，我要让你有来无回。"

他的眼中，闪过一丝凌厉的杀意。

而在城东的废弃矿井中，血影正坐在一张石椅上，等待着手下的消息。

"陈默……"他低声念着这个名字，"你以为你能逃过我的手掌心？"

"很快，你就会知道，什么叫绝望。"

黑暗中，一场更大的阴谋正在酝酿。

而陈默，已经做好了迎战的准备。

这一夜，注定无眠。
